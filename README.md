# Investment Score — Streamlit

Готовое исследовательское веб-приложение с рейтингом **всех 28 акций**, графиками, кнопкой обновления SEC + цен, предварительным расчётом позиции и ручным решением управляющего.

## Публикация без программирования

1. Распакуйте ZIP на компьютере.
2. Создайте **приватный** репозиторий на GitHub и загрузите содержимое папки проекта через **Add file → Upload files** (важно сохранить структуру папок). Для Streamlit Community Cloud может потребоваться разрешить доступ к приватному репозиторию.
3. Откройте https://share.streamlit.io, войдите через GitHub, нажмите **Create app**, выберите репозиторий, ветку `main`, путь `app.py`, затем **Deploy**.
4. В боковой панели приложения введите собственный контактный email для SEC и нажмите **«Обновить данные»**. Загрузка 28 отчётов может занять несколько минут; Yahoo Finance может временно ограничивать запросы.
5. Для локального запуска (необязательно): `pip install -r requirements.txt` и `streamlit run app.py`.

## Что реально работает

- Демо запускается сразу, используя проверенный сохранённый снимок на 20/22 ноября 2026 года.
- Все 28 компаний видны в рейтинге. Неполные оценки помечены и ранжируются отдельно от утверждения их достоверности.
- Кнопка обновляет рыночные цены, технические показатели, SEC Companyfacts, TTM, фундаментальные коэффициенты и Score **в рамках текущей сессии**. Лог ошибок показывается отдельно.
- Если данные не загружены, предыдущая дата сохраняется; обновление не маскирует устаревшие данные.
- Сложные мультиклассовые компании требуют повторной ручной сверки количества акций: обновление не объявляет их полностью подтверждёнными.
- Алгоритм рассчитывает лимит новой позиции, но решение и утверждение суммы остаются за управляющим; отправки ордеров нет.
- CSV можно скачать из интерфейса.

## Ограничения

- **Нет постоянной базы данных.** На Community Cloud состояние приложения может быть сброшено при перезапуске. Решения управляющего необходимо экспортировать.
- Источник цен — неофициальный `yfinance`; доступность и лицензирование данных не гарантированы.
- SEC Companyfacts не содержит всех custom XBRL тегов. Проблемы сопоставимости отдельных отраслей и банков остаются.
- Никаких клиентских персональных данных, токенов или портфельных реквизитов в GitHub не размещайте.
- Текущие значения Score — исследовательские, не подтверждение прибыльности и не индивидуальные рекомендации.

## Структура

`app.py` — веб-интерфейс; `engine/scoring.py` — единая формула факторов; `engine/refresh.py` — обновление; `engine/sec_v2_reference.py` — оригинальная реконструкция SEC; `data/baseline.csv` — сохранённый снимок.
