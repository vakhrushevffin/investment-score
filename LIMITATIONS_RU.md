# Ограничения v2.4.0

- Состав первой сотни зафиксирован на 25 ноября 2026 года по бесплатному снимку [Altstation](https://altstation.io/sp-500-stocks-ranked-by-market-cap/). Позиции `source_rank` отражают порядок бумаг у источника. GOOG и GOOGL образуют одного эмитента, представленного GOOGL. После этого в первую сотню вошла бумага с позиции 101. BRK.B хранится как BRK-B для Yahoo Finance и SEC. HPE добавлена с позиции 223. HON добавлена для регрессии. Рейтинг поставщика и его капитализации могут расходиться с другими источниками.
- CIK всех 102 строк сверен с [официальным справочником SEC](https://www.sec.gov/files/company_tickers.json). CIK идентифицирует эмитента. Для оценки капитализации многоклассовых структур по-прежнему требуется сверка классов, их количества и цен. Новые DELL и BRK-B обозначены для такой проверки.
- SEC Companyfacts покрывает стандартизированные теги с разной полнотой. Для HPE пакетная загрузка не восстановила CapEx, а по DELL оставила флаг проверки капитализации. Полный Score требует четырёх вычислимых факторов. Банковская методология требует отдельного исследования. Обновление SEC отсеивает банковские фундаментальные метрики для дополнительных банков в расширенном наборе.
- Yahoo Finance может ограничивать частоту запросов, менять исторические корректировки и возвращать меньше истории для недавно размещённых компаний. При несовпадении торговых сессий или необъяснённых правках автообновление оставляет действующий архив. Исторические цены датированы последней включённой сессией.
- Реестр не хранит историю состава индекса. Для бэктеста с исключением survivorship bias нужен отдельный исторический состав S&P 500. Текущая первая сотня подходит для мониторинга на дату снимка.
- Данные выдаются из файлов Git, пользовательская сессия Streamlit не заменяет постоянную базу. Перед коммерческой перепубликацией сторонних котировок требуется проверить условия источника.
